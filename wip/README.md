# ZÉMAYA — version en cours

Ouvrez index.html dans votre navigateur pour consulter le site autonome : les images et la vidéo disponibles au moment de l’export sont incluses. Aucun serveur n’est nécessaire pour cette consultation.

Pour consulter ZÉMAYA INSIGHTS, ouvrez insights/index.html. Ses données sont enregistrées uniquement dans ce navigateur ; le mode de prévisualisation est distinct et explicitement fictif.

Pour modifier le projet, installez Node.js 22 ou ultérieur, ouvrez un terminal dans source/, puis lancez npm run dev. Le serveur utilise le port 5173. Les sources sont utilisables sans installation de dépendances.

Le panier fonctionne côté navigateur. Les demandes de commande sont préparées pour WhatsApp : le client doit lui-même appuyer sur Envoyer, puis attendre la confirmation de la boutique. Le formulaire de contact et les paiements ne sont pas raccordés. Aucun paiement ni aucune confirmation de commande ne sont produits automatiquement. Les informations commerciales et juridiques doivent être complétées avant ouverture.

La lecture liée au défilement nécessite une vidéo fournie et un navigateur compatible ; les réglages de réduction des animations sont respectés.

Ce dossier est généré depuis les sources du projet. Conservez vos modifications dans une copie séparée avant de le régénérer.
